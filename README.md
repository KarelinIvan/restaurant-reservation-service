# restaurant-reservation-service
Проект restaurant-reservation-service представляет собой web-приложение, построенное на платформе Django.
Проект разработан для бронирования столиков в ресторане.

Основные функции:
 - Модели данных: Проектирование базы данных и моделей объектов.
 - Реализованы представления для записи, удаления столика и для просмотра всех существующих столиков
 - Реализованы представления для записи, удаления брони и просмотра всего списка брони
 - Данные о столиках и бронировании хранятся в PostgreSQL
 - Список зависимостей проекта записан в файл requirements.txt
 - 


Требования:
 - Python 3.13+
 - Django 5.2
 - djangorestframework==3.16.0

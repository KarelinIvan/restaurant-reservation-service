# restaurant-reservation-service
Проект restaurant-reservation-service представляет собой web-приложение, построенное на платформе Django.
Проект разработан для бронирования столиков в ресторане.

Основные функции:
 - Модели данных: Проектирование базы данных и моделей объектов.

Требования:
 - Python 3.13+
 - Django 5.2
 - djangorestframework==3.16.0
